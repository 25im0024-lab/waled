# تصميم تجارب لتركيبة SPME guar–surfactant gel

تصميم **Box–Behnken** لثلاثة متغيرات (15 تجربة: 12 + 3 نقاط مركزية) ونص Python لتحليل النتائج بنموذج تربيعي.

> **المدى في `make_design.py` قيم مؤقتة وليست توصيات.** عدّلها إلى ما يمكنك تحضيره فعلاً وبما يبقى داخل منطقة single-phase المستقرة لنظامك.
> نصوص التحليل اختُبرت على **بيانات اصطناعية** معروفة الحل فقط، ولم تُجرَّب على قياسات حقيقية.

## الملفات
| الملف | الوظيفة |
|---|---|
| `make_design.py` | يولّد `bbd_design.csv` بترتيب تشغيل عشوائي (عدّل FACTORS وRESPONSES أولاً) |
| `bbd_design.csv` | جدول التشغيل: القيم المرمّزة (−1/0/+1) والحقيقية، وأعمدة فارغة للاستجابات |
| `analyze_bbd.py` | يلاءم نموذجاً تربيعياً لكل استجابة ويطبع ANOVA وLack of Fit وR²، ويبحث عن تركيبة مثلى |
| `requirements.txt` | numpy وscipy وpandas وstatsmodels وmatplotlib |

## المتغيرات (مؤقتة)
| الرمز | المتغير | −1 | 0 | +1 |
|---|---|---|---|---|
| A | حمولة الـ guar (wt%) | 0.20 | 0.30 | 0.40 |
| B | sodium oleate (wt%) | 0.10 | 0.30 | 0.50 |
| C | جرعة microemulsion (2-EH + clove oil) (wt%) | 0.50 | 1.00 | 1.50 |

تحويل تقريبي: 1 lb لكل 1000 gal ≈ 0.012 wt%، فـ 0.20–0.40 wt% ≈ 17–33 lb/Mgal.
ثبّت في كل التجارب: ملوحة الماء (مثلاً KCl)، وpH، ونسبة 2-EH إلى clove oil داخل C، وطريقة وزمن الخلط، وتاريخ القص قبل القياس.

## الاستجابات المقترحة (اختر ما تستطيع قياسه)
| العمود | القياس | لماذا |
|---|---|---|
| `eta100_Tres_cP` | لزوجة عند 100 s⁻¹ عند حرارة الاختبار | حمل الـ proppant أثناء الضخ |
| `eta0p1_25C_cP` | لزوجة عند 0.1 s⁻¹، 25°C | بديل لقدرة التعليق عند قص منخفض |
| `Gprime_1Hz_Pa` | G′ عند 1 Hz داخل المدى الخطي | المرونة التي تبطئ الهبوط |
| `t_half_Tres_min` | الزمن حتى تنخفض اللزوجة إلى 50% | الثبات الحراري |
| `residue_wtpct` | الـ residue الجاف بعد الكسر | ضرر توصيل الشق |
| `settling_mm_s` | هبوط الرمل في أسطوانة مدرّجة | تحقق مباشر من التعليق |

## كيف تجري التجارب
1. شغّل `python doe/make_design.py` (أو استعمل الجدول الجاهز).
2. نفّذ التجارب **بترتيب عمود `run`** (الترتيب عشوائي عمداً لتقليل أثر الانجراف)، وحضّر كل تجربة من **دفعة جديدة مستقلة** حتى النقاط المركزية الثلاث.
3. املأ أعمدة الاستجابات في CSV.
4. حلّل:
   ```bash
   pip install -r doe/requirements.txt
   python doe/analyze_bbd.py doe/bbd_design.csv
   python doe/analyze_bbd.py doe/bbd_design.csv --goal eta100_Tres_cP:max residue_wtpct:min
   ```

## كيف تقرأ النتيجة
- **R² المعدّل وR² التنبؤي** قريبان من بعضهما: النموذج مقبول. فرق كبير يعني ضجيجاً أو فرط ملاءمة.
- **Lack of Fit غير معنوي (p > 0.05):** النموذج التربيعي كافٍ. إن كان معنوياً فالسطح أعقد (مثلاً حافة منطقة طور).
- معاملات **التفاعل** (A:B …) تقول هل يعتمد أثر متغير على قيمة آخر.
- قيمة **optimum** تنبؤ نموذج. نفّذ **2–3 تجارب تأكيد** عندها قبل أن تعتمد عليها.

## تحفظات
- صالح داخل المدى المجرَّب فقط.
- النقاط المركزية الثلاث تعطي تقديراً ضعيفاً للخطأ التجريبي (درجتا حرية). كرّر أكثر إن كانت التكلفة معقولة.
- يفترض النموذج تغيراً سلساً. أنظمة microemulsion قد تغيّر طورها فجأة، فتحقق من الشكل (turbidity، فصل طوري) في كل تجربة.
- إن كانت الحرارة أو الملوحة متغيراً مهماً عندك، أضفها كمتغير رابع (CCD أو تصميم أكبر) بدل تثبيتها.
