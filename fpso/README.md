# FPSO Console — محاكي وحدة FPSO

▶ **https://25im0024-lab.github.io/waled/fpso/?lang=ar** (بالعربي) · [English](https://25im0024-lab.github.io/waled/fpso/?lang=en)

محاكي تفاعلي لوحدة إنتاج وتخزين وتفريغ عائمة (FPSO)، وهو تطبيق مستقل يُثبَّت بأيقونته الخاصة (PWA) ويعمل بدون إنترنت. يغطي المسار كله: من المكمن والآبار تحت البحر، إلى الـ manifold والـ risers والـ turret، ثم المعالجة على السطح، وصولاً إلى التخزين والتفريغ إلى ناقلة مكوكية. اضغط أي جزء من الرسم أو أي بارامتر ليظهر شرحه بالعربي أو الإنجليزي.

## ما يمكن التحكم فيه
- **الآبار (P-1 إلى P-4):** فتح وإغلاق، وفتحة الـ choke، وغاز الرفع (gas lift). يعرض لكل بئر الإنتاج ونسبة الماء و WHP/BHP وحالته (يتدفق، لا يتدفق، مغلق).
- **ما تحت البحر:**
  - ضغط الـ manifold.
  - حرارة الوصول مقابل حرارة الهيدرات، وزمن التبريد المتبقي، وحقن MEG.
  - مؤشر الـ slugging في الـ riser.
  - ضغط المكمن ونقطة الفقاعة، و VRR.
- **المعالجة على السطح:**
  - الفاصل ثلاثي الأطوار: الضغط والمستوى المطلوبان، و BS&W النفط.
  - قطارا ضاغط 2×50 %، وتوزيع الغاز بين الوقود والرفع والتصدير وإعادة الحقن والشعلة.
  - معالجة الماء (OIW)، وحقن ماء البحر.
  - الطاقة: الطلب مقابل المتاح، والتحول إلى الديزل.
- **التخزين والتفريغ:** الحمولة والغاطس والأيام المتبقية حتى الامتلاء، وتسلسل الناقلة المكوكية (اقتراب ← ربط ← تفريغ ← فصل ← مغادرة) مع حد الطقس.
- **التثبيت والطقس:** الرياح والأمواج والتيار. منظر علوي يُظهر دوران السفينة حول الـ turret (weathervaning)، والإزاحة، وشدّ الخطوط التسعة.
- **الإنذارات والأحداث:** ESD و PSD، والإنذارات، وسجل الأحداث، ومنحنيات حتى 3 أيام، وسرعة محاكاة حتى 3600×.
- **سيناريوهات المدرّب:** توقف ضاغط، ووصول الماء إلى بئر، وانقطاع خط تثبيت، وعاصفة، واتساخ الـ hydrocyclones، وتعطّل صمام مستوى، واستنزاف سريع للمكمن.

## النموذج (تدريبي، والمعاملات توضيحية)
- **المكمن:** موازنة مادية بالانضغاطية الكلية، مع تعويض الفراغ بحقن الماء وإعادة حقن الغاز.
- **الآبار:** IPR مركّب (خط مستقيم فوق نقطة الفقاعة، و Vogel تحتها)، وحلّ عُقدي لكل بئر: هيدروستاتيكي الأنبوب مع تخفيف الغاز والاحتكاك، و choke تحت البحر.
- **الـ manifold والـ riser:** هيدروستاتيكي + احتكاك، ومؤشر slugging، وتبريد حرارة الوصول مقابل منحنى هيدرات تقريبي.
- **الفاصل والغاز:** فاصل بتحكم بالمستوى والضغط، و PCV و PSV إلى الشعلة. قدرة الضغط بمعادلة أديباتية متعددة المراحل مع تبريد بينيّ، وغاز الوقود = القدرة ÷ (كفاءة التوربين × القيمة الحرارية).
- **التثبيت:** صلابة شبه ساكنة مع قوى رياح وتيار وانجراف أمواج، ومكوّن ديناميكي للشدّ.

## البناء والاختبار

```
node fpso/build.js            # ينتج fpso/index.html
node fpso/tests/sim-smoke.js  # يختبر IPR والحالة المستقرة والـ choke والـ gas lift وتوقف الضاغط والـ ESD والهيدرات والتفريغ والعاصفة والتثبيت والـ slugging والمكمن
```
المصدر في `src/`: `page.html` و `style.css` و `i18n-ar.js` و `info.js` (الشروحات) و `sim.js` و `ui.js`. ملف الترجمة المشترك هو `../drillers-console/src/i18n.js`.
