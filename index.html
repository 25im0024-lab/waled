Petroleum Engineering ToolsDrilling · Offshore production · Fracturing fluids

Free training simulators, a field-data hydraulics calculator, fracturing-gel research tools and guides. They run in the browser and work offline once installed. Each tool also has an Arabic interface (العربية) inside it.

Tools

Driller's ConsoleRig control-panel simulator

Training

An interactive drilling-rig control panel:

  • Auto-driller, top drive and mud pumps.
  • Mud circulation and a PDC bit.
  • BOP and kill sheet, with kick and loss scenarios.
  • Alarms and live trends.
Open

Field HydraulicsCalculator for field data

API RP 13D · Herschel–Bulkley

Enter your well and get the results:

  • Inputs: geometry, survey, Fann readings, pumps and nozzles.
  • Results: SPP, ECD, bit hydraulics and hole cleaning.
  • Check: compare them with measured values.
Open

FPSO ConsoleOffshore production simulator

Separate app

A complete floating production, storage and offloading unit: from the reservoir and subsea wells through the manifold, risers and turret mooring, to separation, gas compression and water treatment, then storage and offloading to a shuttle tanker.

Live ROV and inside-the-vessel cameras, a helideck with a helicopter, crew at their stations and day/night lighting. Tap any part of the drawing for its explanation.

OpenFull guide (PDF)

FracGel LabNaOA / KCl / guar fracturing gel

Research workbench

A workbench for a fracturing gel built from wormlike micelles and guar:

  • Sample matrix with controls and a synergy index.
  • Maxwell analysis of frequency sweeps, power-law flow curves and proppant settling.
  • Desirability ranking of formulations and a response surface that proposes a verification point.
Open

Frac Gel Lab 3DVirtual fracturing-gel lab

Presentations

Prepare a NaOA / KCl / guar gel in a 3D lab:

  • A nano view showing the change from solution to wormlike micelles.
  • Rheometer, proppant suspension, heating, and breaking with APS or dilution with deionized water.
  • A water-bath break test with Cannon–Fenske viscosity measurement.

Presentation mode works with a clicker.

Open

Parameter GuideDriller's Console & Field Hydraulics (PDF)

English + Arabic · 18 pages

Explains the role of every parameter and how to read it, including the mud circuit, the PDC bit, the kill sheet and the alarms.

It also lists every equation used by the simulator and the calculator, with an explanation, and states whether each one is a standard or a model assumption.

Open PDF

Note: the simulators are simplified training models, not calibrated against a real rig or vessel. The calculator is an engineering aid, not validated software: compare its results with real measurements (SPP, and ECD from PWD) before using them for any decision.

Install as an app

AndroidChrome

  1. Open the tool's link.
  2. Menu ⋮ → Install app or Add to Home screen.

iPhone / iPadSafari

  1. Open the tool's link in Safari.
  2. Share button → Add to Home Screen.

ComputerChrome / Edge

  1. Open this page (it installs as one app with all the tools) or any tool's link to install that tool alone.
  2. Chrome: the install icon ⊕ at the end of the address bar, or menu ⋮ → Cast, save and share → Install page as app.
  3. Edge: menu ⋯ → Apps → Install this site as an app.
  4. If no install option appears: menu ⋮ → Cast, save and share → Create shortcut, and tick Open as window.

After installing, long-press the app icon (or right-click it on a computer) for shortcuts that open the calculator or the guide directly. The app works offline after the first visit.
