# English Hub — تعلّم الإنجليزية (A1 → B1)

أداة مستقلة عن IELTS Coach لتعلّم الإنجليزية من المبتدئ إلى المتوسط، بواجهة عربية ونصوص إنجليزية، وكل شيء فيها بالعربي والإنجليزي معًا. صفحة ثابتة بلا سيرفر ولا build، تعمل أوفلاين بعد أول تحميل (PWA).

## التشغيل

- **محليًا:** من جذر المستودع `python3 -m http.server` ثم افتح `http://localhost:8000/english/` (الميكروفون يحتاج `https` أو `localhost`). يمكن أيضًا فتح `english/index.html` مباشرة، لكن الأوفلاين (service worker) والميكروفون لن يعملا.
- **GitHub Pages:** نفس إعداد IELTS (`Settings → Pages → Deploy from a branch → / (root)`). يصبح الرابط `https://<user>.github.io/<repo>/english/`.

## حدود يجب معرفتها

- **الترجمات العربية** كتبها Claude ولم يراجعها مدرّس معتمد؛ قد توجد صياغات تحتاج تحسينًا.
- **الصوت** من محرّك المتصفح (صناعي) وجودته تختلف بين Chrome/Edge/Safari والأجهزة.
- **تقييم الكلام** يقارن ما فهمه المتصفح بالنص: مؤشّر تقريبي لتطابق الكلام وليس تقييم نطق رسميًا. بلا ميكروفون يعمل التدريب بنمط «قلتُها».
- **فحص الكتابة** يبحث عن أنماط محدّدة ولا يفهم المعنى. المراجعة الأعمق من مدرّس أو من ميزة Claude الاختيارية.
- رسوم وضع الفم تبسيطية للتوضيح فقط.

## ميزات Claude الاختيارية

من الرئيسية ← الإعدادات ← «ميزات Claude الاختيارية»: أدخل مفتاح Anthropic API لتحصل على (1) ملاحظات على نصّك في الكتابة بشرح عربي وتقدير مستوى CEFR، (2) محادثة عمل حرّة مع Claude في دور من السيناريو مع تصحيحات بالعربية.

- الطلب يخرج من متصفحك مباشرة إلى `api.anthropic.com` عبر SDK الرسمي المضمَّن في `vendor/anthropic-sdk.js` (لا CDN).
- الافتراضي `claude-sonnet-5-5` (أرخص، يكفي للمحادثة)، ويمكن اختيار `claude-opus-5-5` أو `claude-fable-5-1`. التكلفة المعروضة تقدير تقريبي.
- المفتاح في `sessionStorage` إلا إذا اخترت «تذكّر» فيُحفظ في `localStorage`. استخدم مفتاحًا بحد إنفاق منخفض ولا تستخدمه على جهاز مشترك.
- هذه الميزات لم تُجرَّب على الـ API الحقيقي في الاختبارات الآلية (استُخدم SDK مزيّف للتحقق من الواجهة فقط).

## الاختبارات

```bash
cd english/tools
node validate-data.js          # مفاتيح الإجابات، وجود العربية، التكرارات، النماذج المرجعية…
npm install && npx playwright install chromium
node e2e/run.js                # تشغيل كل الأقسام في Chromium، ~55 فحصًا
```

يعمل نفس الأمر تلقائيًا في GitHub Actions ([`english-ci.yml`](../.github/workflows/english-ci.yml)).

## هيكل الملفات

`js/core.js` (الحالة، الصوت، SRS، الراوتر) · `js/quiz.js` (محرّك التمارين) · `js/visuals.js` (رسوم SVG التفاعلية) · `js/dialogue.js` (الحوارات والأدوار) · `js/ai.js` (Claude الاختياري) · `js/data/*` (المحتوى) · `js/mod/*` (الأقسام) · `sw.js` (أوفلاين).
